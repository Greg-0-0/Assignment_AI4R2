# Assignment D3-V1: Warehouse Robotics – Single Robot Pick-and-Deliver - AI4R2
The assignment required to model a warehouse environment using PDDL lagnuage. The scenario featured a single mobile robot capable of picking up packages and delivering them to predefined locations.

The implementation is divided into two parts:
- A PDDL model which provides basic navigation capabilites of a multi-structured environment, and package manipulation for pick and drop actions.
- A PDDL+ model that, in addition to the previous features, introduces time for robot movements to simulate missed deadlines in package distribution.
